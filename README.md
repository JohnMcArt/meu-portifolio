## Galeria de trabalhos visuais
Há 30 espaços editáveis para imagens e vídeos. Clique em um espaço e escolha um arquivo para pré-visualizá-lo localmente. Para publicar no GitHub Pages, coloque as mídias dentro da pasta do projeto (recomendado: `assets/artes/`) e atualize o HTML para usar caminhos relativos, por exemplo `<img src="assets/artes/minha-arte.jpg" alt="Descrição da arte">`. A pré-visualização por seletor de arquivo não salva o arquivo no site automaticamente.

As imagens são exibidas com `object-fit: contain`, então formatos e proporções diferentes ficam inteiros, sem corte. Isso pode deixar faixas vazias em alguns quadros; é preferível a cortar uma arte sem autorização.

## Publicação
Envie `index.html`, `style.css`, `script.js` e a pasta `assets/` para o repositório publicado no GitHub Pages.


## Galeria de artes e vídeos

A seção **Artes** agora usa um mosaico responsivo com os arquivos da pasta `imagens/`. Imagens e vídeos incluídos no projeto já aparecem na galeria. Para adicionar novas mídias, coloque os arquivos nessa pasta e adicione um cartão correspondente no bloco `galeria-mosaico` do `index.html`, usando `img` para imagens ou `video` para vídeos. Use nomes de arquivo simples, sem espaços ou acentos, para facilitar a publicação no GitHub Pages.
